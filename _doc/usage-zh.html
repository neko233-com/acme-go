acme-go 使用说明

acme-go 通过 ACME 协议申请和续期免费 SSL 证书。主配置是 config_acme.json，DNS 密钥等私密信息放在 config_acme.local.json。

快速开始

  1. 确认你的域名托管在哪一家 DNS 云厂商。
  2. 在云厂商后台创建可修改 DNS TXT 记录的 API token 或 access key。
  3. 把证书域名、输出目录、DNS provider 写入 config_acme.json。
  4. 把私密凭据写入 config_acme.local.json。
  5. 运行 acme-go validate -config config_acme.json 检查配置。
  6. 运行 acme-go issue -config config_acme.json -name neko233-staging 申请证书。
acme-go providers
acme-go validate -config config_acme.json
acme-go paths -config config_acme.json -name neko233-staging
acme-go issue -config config_acme.json -name neko233-staging

已准备好的域名

当前准备好的泛域名证书条目是 neko233-staging，域名写作 _.neko2public.online，这里用下划线表示通配符，方便作为 Windows/Linux/macOS 都能落盘的目录名。输出目录是：

output_SSL/_.neko2public.online/

申请成功后会得到 cert.pem、privkey.pem、pubkey.pem、fullchain.pem、issuer.pem 和 metadata.json。

证书如何使用

nginx

ssl_certificate     /path/to/acme-go/output_SSL/_.neko2public.online/fullchain.pem;
ssl_certificate_key /path/to/acme-go/output_SSL/_.neko2public.online/privkey.pem;

Caddy

tls /path/to/acme-go/output_SSL/_.neko2public.online/fullchain.pem /path/to/acme-go/output_SSL/_.neko2public.online/privkey.pem

Windows 或图形化面板

一般选择 fullchain.pem 作为证书链，选择 privkey.pem 作为私钥。output_SSL/ 适合备份，但不要提交到 Git。

各云厂商凭据字段

可以优先填写 dns.credentials，acme-go 会自动映射成 lego DNS provider 需要的环境变量；如果你在 dns.env 里显式写了环境变量，则显式值优先。

本地密钥文件示例

{
  "account": { "email": "ops@example.com" },
  "dns_providers": {
    "aliyun-cn": {
      "credentials": {
        "access_key": "your-access-key",
        "secret_key": "your-secret-key"
      }
    }
  }
}
